# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security seriously, especially given the local execution of LLM generation and interaction with developer file systems.

If you discover a security vulnerability within this project:
1. **Do not open a public issue.**
2. Report the vulnerability via private GitHub advisory or by contacting the repository maintainers.
3. Include detailed reproduction steps, system details, and potential impact.

We will acknowledge receipt within 48 hours and coordinate a disclosure timeline.
